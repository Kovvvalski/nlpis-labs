How to Use

Follow these simple steps to use the Syntax Tree Visualizer:

  • Step 1: Upload a text file by clicking on the "Choose a text file" button.
  • Step 2: After selecting the file, click "Parse Sentences from File" to send it to the server.
  • Step 3: The system will parse each sentence from the text file and generate syntax trees for each sentence.
  • Step 4: Each sentence will be displayed with its corresponding syntax tree(s). If the sentence can't be parsed, an error message will be shown.

Happy visualizing!
